# design

- `marks/`: four text drawings of the Faraday mark (`a-cage.txt`,
  `b-mesh-shield.txt`, `c-caged-key.txt`, `d-keyhole-shield.txt`) and
  `options.png`, the options side by side.
- `prototype/project/`: an early interface mock-up, a design canvas
  (`canvas.json` plus one `.dc.html` page per screen: boot, unlock, vaults,
  wallets, spend and others). `canvas.json` is dated 2026-10-04; git history
  shows 2026-10-11 as the last change, the date the repository was started
  afresh.

The prototype is frozen. It is not the source of truth for the app:
`docs/DESIGN.md` and `faraday-ui` are. Some code comments refer to a
prototype page as the origin of a layout.
