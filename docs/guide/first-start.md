# First start

**Kind:** Reference
**Status:** Checked against the app
**Screen:** `Home`
**Key:** first-start

The guide opens here from Home while nothing is loaded and nothing is under way. **Make a new wallet** makes the keys and the wallet, **Restore an existing wallet** brings one back from its backups, and **Check a signer** checks another device's seed, addresses and signatures; every other tool is under **Tools**.
