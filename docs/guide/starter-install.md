# Install and Installed

**Kind:** Reference
**Status:** Checked against the app
**Starter page:** `Install`, `Installed`
**Key:** starter-install

Install copies Faraday Starter to this computer; the top bar offers **Install** while nothing is installed and **Update** while the installed copy is older. Installed lists what is installed and where, from the menu's **Uninstall**.

## Install

**Key:** starter-install.install

**Install** copies the Starter in one press and then shows **Installed in** the folder it went to, with **Done**. While the installed copy is older, the page shows the **Installed version** and **This version**.

## Installed

**Key:** starter-install.installed

Shows **Not installed**, or the **Installed version** with a row for each of **Faraday Starter**, **Menu entry**, **Icon**, **Installed apps entry** and **Settings** that exists, and where it is.

**Uninstall** asks **Uninstall Faraday Starter?** once and removes the files listed. Received files and Faraday Demo's sticks stay.
