# Starter: Tools

**Kind:** Reference
**Status:** Checked against the app
**Starter page:** `Tools`
**Key:** starter-tools

Tools holds two cards that need no stick: Transfer and the printable blank templates.

## Transfer

**Key:** starter-tools.transfer

**Open Transfer** opens Transfer to send and receive files and text.

## Blank templates

**Key:** starter-tools.templates

**Open blank templates** opens the printable sheets a seed is copied onto by hand, in Words, SeedQR, codex32 and Krux code forms.
