# Start this computer from the stick

**Kind:** Reference
**Status:** Checked against the app
**Starter page:** `Start`
**Key:** starter-start

The steps to restart this computer into the BIOS, turn Secure Boot off, start from the stick and turn Secure Boot back on, in the order this computer needs. On a Mac the page is **Start this Mac from the stick**.

## Choices

**Key:** starter-start.steps

**Restart into the BIOS** asks once, with a reminder to save work, then restarts; with Secure Boot off and a stick attached, **Restart to choose a device** restarts to Windows' device menu. **I have its rescue disk or password** is asked first where another encryption product guards a drive. **Temporarily suspend BitLocker** and **Resume BitLocker** appear where BitLocker is on. **Print** makes a sheet of what is under **Write down**. **Check again** re-reads a TV, a KVM switch or a virtual machine found on this computer, and **Continue anyway** lets a TV or a KVM switch through.

The steps for each computer are in [Starting a Windows computer from the stick](../learn/faraday/boot/windows.md), [Starting a Linux computer from the stick](../learn/faraday/boot/linux.md), [Starting an Intel Mac from the stick](../learn/faraday/boot/mac-intel.md) and [When the stick does not start](../learn/faraday/boot/not-starting.md).
