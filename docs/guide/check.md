# Check

**Kind:** Reference
**Status:** Checked against the app
**Screen:** `Check`
**Key:** check

What to hold up against a hardware wallet, one row for each thing to check, in groups. A row opens the tool that does it, and **Back** returns to Check; each tool is also on the Tools page.

## The wallet and signing

**Key:** check.signing

**An address on its screen** opens Check an address. **A transaction before signing** opens Decode a transaction. **What it signed** opens Check a signer, which compares the PSBT sent and the one returned. **Its signatures hide nothing** opens Nonce check.

## Setup and backups

**Key:** check.setup

**A seed made from dice rolls** opens New key at its dice source. **A backup in another form** offers **SLIP-39 shares**, **Seed XOR parts**, **SeedQR**, **codex32** and **Krux code**, each opening its tool. These rows are marked **Seed**: they work from the seed.

## Messages and keys

**Key:** check.messages

**A signed message** opens Check a signed message. **Child seeds** opens Child seeds and passwords, marked **Seed**. **An xpub's other spellings** opens Convert an xpub.
