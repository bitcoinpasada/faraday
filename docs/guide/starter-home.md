# Starter: Home

**Kind:** Reference
**Status:** Checked against the app
**Starter page:** `Home`
**Key:** starter-home

Home shows this computer, the checklist for starting it from a Faraday stick and the cards that apply to it. One button on the This computer card is the next step.

## This computer

**Key:** starter-home.computer

The card names this computer and its Secure Boot state, or on a Mac its model. Its button is the first that applies.

**Make a Faraday stick** is shown with no stick attached or on a computer that cannot start one. **Restart into the BIOS** is shown while Secure Boot is on or unknown, and **Restart from the stick** while it is off. **Start this Mac from the stick** opens the start steps on a Mac. **I have its rescue disk or password** is shown first where another encryption product guards a drive. A restart is held by a TV, a KVM switch or a virtual machine.

## Checklist

**Key:** starter-home.checklist

Each row opens its page. **Make a Faraday stick** shows **No Faraday stick attached** or the attached stick's version, and opens the disks. **Start this computer from the stick** (**Start this Mac from the stick** on a Mac) shows the Secure Boot state and opens the start steps. **Turn Secure Boot back on** is shown only while Secure Boot is off and opens the same steps.

The next step is marked: the first of the stick and the start that is not done.

## Faraday Demo

**Key:** starter-home.desktop

Not shown on macOS. **Open Faraday Demo** opens Faraday Demo inside the Starter, with the version shown on the card.

## Update

**Key:** starter-home.update

Shown as **Update the installed Faraday** while the installed Starter is older than the one running. **Update** opens the install page.

## Boot entry

**Key:** starter-home.boot-entry

Shown on Linux with no stick attached, while this computer's boot list holds a Faraday stick entry. **Remove the Faraday boot entry** removes it.
