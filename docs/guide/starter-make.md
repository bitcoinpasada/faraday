# Starter: Make

**Kind:** Reference
**Status:** Checked against the app
**Starter page:** `Make`
**Key:** starter-make

Make writes a Faraday image onto a disk, in two cards: a Faraday stick and a Pi card. Each button opens the disks.

## Faraday stick

**Key:** starter-make.stick

The card shows **No Faraday stick attached**, or the version of the stick attached. **Make a Faraday stick** is the main button while no stick is attached and a lesser one when one is.

## Pi card

**Key:** starter-make.pi

The card shows the version of the Pi image, or **No image found**. **Make a Pi card** opens the disks only when the Starter has a Pi image.
