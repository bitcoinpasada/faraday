# Inside a vault

The open vault's page: its kinds of record (Bitcoin keys, wallets, entries,
notes, GPG keys, Secure Boot), each item's pane with its secrets behind an
eye, the item forms, search, the Load sheet that loads keys and wallets into
the session, copying and moving items between vaults, the vault's key file,
Save to a stick and KeePass export. It is for the person on the offline
device or in Faraday Demo. It is reached from a vault card's View contents,
from the end of an unlock (`vault-unlock`), from Home search and Tools, and
from the backup and signing flows that open a vault's item.

## Screens and sheets

- Vault contents `Screen::VaultContents` (`contents`, `faraday/faraday-core/src/vault/screen.rs:~1806`; `contents_compact`, `~2197`). With no vault open: "No vault is open" and an open button (`~1816-1823`, `~2208-2215`).
- Head (`seals_head`, `~1755-1804`): seal count, warning, read-only reason, unreadable-record count, "needs key file" line.
- Top actions: Lock (`LockAsk`, `~1854`), Rename (`V::Rename`, hidden when read-only, `~1863-1875`), More `⋮` (`V::MoreAsk` when `more::shown`, `~1877`), tabs `V::Show(i)` when more than one vault is open (`~1900-1913`), Change passphrase (`V::ChangePassphrase`) and Memory (`V::MemoryAsk`), editable vaults only (`~1922-1925`), Write to stick (`Action::WriteAsk`, `~1926`), kinds (`V::Category(k)`), add (`V::AddKind(k)`, editable), Scan a code into an entry (`V::ScanEntry`, Entries), Import all entries (`V::ImportAllEntries`, Entries, when the Inbox has Entries files, `~2008-2016`), TOTP codes (`Action::OpenCodes`, `~2040`), GPG Restore (`backup_flow::gpg_restore::contents_button`, GPG keys, `~2018-2022`), search bar (`~2054-2056`).
- Categories (`CATEGORIES`, `faraday/faraday-core/src/vault/area.rs:3857`; `~3857-3867`): Bitcoin keys [KEY, PASSPHRASE, CODEX32_SHARE], Wallets [WALLET, WALLET_SHARE], Entries [ENTRY], Notes [NOTE, SHEET], GPG keys, Secure Boot. Kinds are listed only when they hold something or are chosen (`faraday/faraday-core/src/vault/screen.rs:~2086-2112`).
- Item headings (`item_heading(_of)`, `~1468`, `~1487`) per kind KEY, WALLET, ENTRY, NOTE, SHEET, GPG, SECURE_BOOT, WALLET_SHARE, CODEX32_SHARE, PASSPHRASE. A note's heading is its first line, first 40 characters (`~1549`). Key and wallet headings add "not loaded at unlock" when `!loads_at_unlock()` (`~1508-1525`). The item title reads "Vault {} · {}", as the plan's (fix b8920c0be).
- Empty vault: `NOTHING_YET`, `empty_buttons` (`~2116`), add rows (`~2158`).
- Unread section (`faraday/faraday-core/src/vault/screen/unread.rs`): "Not read here · n", items the store could not read, each with title and fault, no actions. A refused KeePass wallet item is listed as Unreadable with the rule's reason (fix 95d5cec38).
- Item pane (`item_pane`, `faraday/faraday-core/src/vault/screen.rs:~2898`; `detail`, `~2442`): picks the form, the prompt, the saving panel, Secure Boot images, signing or the item. Actions: Trim (`V::TrimAsk(field)`, not read-only, only for codex32 or child key fields, `2934-2942`), Copy to (`V::CopyTo`), Move to (`V::MoveTo`), Delete by hold (`hold_delete`, called at `2960`), GPG hold to mark revoked (`V::GpgHoldRevoke`, `~2962-2974`).
- Key rows (`key_rows`, `~2979`): fingerprint; words behind an eye (`V::Reveal`); SeedQR only for English mnemonics (`~2991`); BIP-39 passphrase stored or not; load at unlock; in-session state; Load into session (`V::Load`) when not loaded; Load with passphrase (`V::LoadWithPassphrase`) when `reads && !r.has(KEY_PASSPHRASE)` and not loaded, inside `if !here` (`3036-3042`); Open in Explore (`Action::ExploreKey(fp)`), Back it up (`Action::Backup(w)`, only when a session wallet uses it) and Convert (`Action::Convert(OpenOn(fp))`), all three only when loaded (`~3047-3061`); toggle load at unlock (`V::ToggleLoad`), hidden when a wallet supplies it (`~3063`); Save to a stick (`V::SaveToStick`) when the record has words (`~3073`).
- Wallet rows (`wallet_rows`, `~3080`): chart (glance), descriptor, load at unlock, Open in Wallets (`V::Load`), backup checklist (`V::ChecklistOf(v, i)`), toggle load, Show as QR (`V::WalletQr`, not for a silent-payments warning or a held record, `~3097-3104`, `~3127`), Save to a stick.
- Entry rows (`~3135`): username, password, URL, TOTP code and secret, notes, each secret behind an eye (`V::Reveal(id)`); TOTP QR (`codes::totp_qr_button`), `Action::OpenCodes`, Edit (`V::Edit`), Export for KeePass (`V::ExportKdbx`). Note rows (`~3170`). Sheet rows (`~3183`): descriptor, note, QR/PNG (`Code::VaultSheet`).
- GPG rows (`gpg_rows`, `~3197`): see `gpg-keys`.
- Secure Boot rows (`~3338`): owner GUID; PK/KEK/db names (zipped with 3 labels; a short `names` drops rows with no message); Windows-compatible vs own-keys-only (`V::SbOwnOnly`); enrolment is a hold with the Warning tone (`~3384-3395`) because "neither list holds Microsoft's third-party certificates" (`~3382-3383`); `V::SbImages`; Back up first replaces the actions while a backup waits (`~3374-3378`).
- Form pane (`form_pane`, `~2474`): entry, note, rename vault, GPG key, GPG revocation (detected by field index 3, `~2481`), Secure Boot keys; Save labels "Make the key", "Make the revocation", "Make the keys", "Save".
- Entry form (`faraday/faraday-core/src/vault/screen/codes.rs`): always a new entry; a text area for multiline, a secret box with `password_chip` for masked, a text box otherwise; Save `V::FormSave`, Cancel `V::FormCancel`.
- Masked secret (`faraday/faraday-core/src/vault/screen/secret.rs:~8-79`, `~168-195`): 24 dots until the eye is pressed; the value is built into a `SecretText` only while shown (`~61`). `seedqr_box`/`code_with` (`~114-166`) draw a SeedQR or code behind an eye (`V::ShowSeedQr`).
- Prompt pane (`prompt_pane`, `faraday/faraday-core/src/vault/screen.rs:~2567`): the passphrase for loading a key, for a wallet, for a KeePass export ("Seal and export") or for its check ("Check made open" / "Skip"). Go is primary only when the check is not an empty KeePass one and the two passphrases agree (`~2661-2663`); "pass pair differ" when the second differs and is not empty (`~2628-2632`).
- Search (`faraday/faraday-core/src/vault/screen/search.rs`): search bar (× clears), an items column on a wide window, a compact search view, item rows with Load / Loaded (`V::LoadRow`), "none" lines (searched-empty vs none of the kind); the selection shows only without a form and when not saving.
- Load sheet `Sheet::UnlockLoad` ("Load from {vault}", `faraday/faraday-core/src/vault/load_screen.rs:~28-87`): a card per wallet, a Keys card for keys in no wallet, Load ticked / Not now. The button says the count (fix 46ea72627).
- Load with a passphrase `Sheet::PassphraseSeeds` ("Seeds with no passphrase stored", F62, `faraday/faraday-core/src/vault/load_screen.rs:~237-355`): pick a seed, type its passphrase, Load.
- Copy and move `Sheet::CopyTo` (`faraday/faraday-core/src/vault/copy_screen.rs:~164-207`; the same sheet with `ask` set is the confirm dialog): rows `Dest::{Open(VaultId), Locked([u8; 32]), New}`.
- Save also `Sheet::SaveAlso` (`faraday/faraday-core/src/vault/load_screen.rs:~400-436`).
- Keep choices `Sheet::SaveKeeps` (`faraday/faraday-core/src/vault/keep.rs:~260`; dialog `draw_keep`, `faraday/faraday-core/src/vault/copy_screen.rs:~127-161`); also on `Sheet::SecretOut` (`faraday/faraday-core/src/vault/keep.rs:~190`, `~193`). Heads show only with more than one seed (`faraday/faraday-core/src/vault/copy_screen.rs:~136-137`).
- Key file menu `Sheet::KeyFile`, `More::{Menu, Key, Pick}` (`faraday/faraday-core/src/vault/more.rs`): ⋮ opens one line "Key file" (`~57-69`, `~384`); the dialog has Make a key file, Choose a file, Remove key file, Cancel (`~72-78`).
- Trim `Sheet::Trim` (`faraday/faraday-core/src/vault/trim.rs`): drops the custom codex32 (`KEY_CODEX32`) or BIP-85 child (`KEY_CHILD`) field of one seed at the next seal.
- Save to a stick `Sheet::VaultSave`: for a key, words (and SeedQR only if English) to a stick; for a wallet, descriptor, QR picture, Sparrow, hardware-signer and Bitcoin Core files to the Outbox (`vault_stick_save_open`, `faraday/faraday-core/src/vault/mod.rs:~4432-4475`; `wallet_save_files`, `~4500`; `vault_stick_save_write`, `~4548-4610`; types `SaveWhat::{Words, SeedQr, Public}`, `SaveFile`, `StickSave` in `faraday/faraday-core/src/vault/out.rs:~14-70`).
- The Save panel (`faraday/faraday-core/src/vault/screen/save.rs`): offers plain or with-passphrase by what the vault holds (fixes 04fe34ba7, 0cd32bb13, 6c130697a).

## Effects

- Load job: `app.start(Job::KeysLoad(..), EN.working_load_seeds)` (`faraday/faraday-core/src/vault/load_job.rs:~149`); `KeysJob::run` on the worker (`~53-58`); then on the main thread `session.keys.adopt_loaded_derived` (`~164`), `vault_load_wallets` (`~132`, `~166`), the `loads_started` counter (`~148`). Wallets are added without their keys (`add_wallet_kept`); Wallets opens when pressed from a row or a selection.
- A key with a typed passphrase: the key record is stretched in a job and the fingerprint toasted; `load_key_with_passphrase` on the store (`faraday/faraday-core/src/vault/mod.rs:~1085-1091`, `~3830`).
- KeePass export: a selected ENTRY record goes into a new KeePass file sealed under the typed passphrase, in the Outbox (`Job::Kdbx`, cost `STEPS_KIB[0]`, 3 passes, 4 lanes; `faraday/faraday-core/src/vault/stretch.rs:~667-824`, written at `~737`; built through `crate::bip85::kdbx_out`, `~704`). Then a check (`Purpose::KdbxCheck`) opens the file once more with the passphrase. An export goes beside a same-named file in the Outbox, never over it (fix 6c5190f9c).
- Key file: `VKeyMake` draws 32 random bytes (`fresh_bytes(b"vault key file", 32)`, `faraday/faraday-core/src/vault/more.rs:~270`) and writes `<vault name>.keyx` (with `-2`, `-3`.. when taken; `free_keyx`, `~246-262`, `.kdbx` stripped) to the Outbox through `outbox_secret(OutReason::KeyFile)` (`~297`); a toast says the next seal takes it. Numbering goes on until a free name is found (fix 5258e5b1e).
- Save to a stick: words and SeedQR go to the Outbox only through `outbox_secret(OutReason::VaultStick)` (`faraday/faraday-core/src/vault/mod.rs:~4595-4597`); the public files separately; toast `secrets_waits_unprotected` for seed files.
- Item edits mark the vault changed; they are written at the next seal (`vault-seal`).
- Adding an entry from a scan opens the camera (`ScanEntry`).
- Randomness for a KeePass export and its entries: 32 bytes each (`faraday/faraday-core/src/vault/stretch.rs:~686-701`); `RequestEntropy` when the pool is empty.

## State and lock

- Contents state is in `Vaults` (see `vault-list-create`): `current`, `category`, `category_chosen`, `category_scroll`, `item`, `item_open`, `form`, `saving`, `focus`, `prompt`, `shown`, `words`, `paperkey`, `seedqr`, `code`, `codes`, `search`, `load`, `pass_seeds`, `copy_to`, `copy_wait`, `keep_save`, `save_hold`, `stick_save`, `trim`, `moved`, `moved_subjects`, `more`, `key_chosen`, `key_outbox`, Secure Boot fields (`sb_owner`, `sb_own_only`, `sb_images`, `sb_sign`, `sb_checked`, `faraday/faraday-core/src/vault/area.rs:~2556-2566`).
- Secrets on the item page:
  - Words are a borrow of the held `Mnemonic` (`app.record_words_held()`, `faraday/faraday-core/src/drawing/allowed.rs:68`; `faraday/faraday-core/src/vault/area.rs:1292`), only while the eye is open; `words_text` builds a wiping `Text` copy per frame.
  - `reveal_record` lends a `Revealed<'_>` borrow through the `Allowed::SecretShown` gate (`faraday/faraday-core/src/drawing/allowed.rs:94-106`); no copy is kept.
  - The paperkey is made only while shown (`faraday/faraday-core/src/vault/screen.rs:~3226-3235`), held as `Held<Text>`.
  - Words, paperkey and TOTP codes are computed once and held while shown (fix 92e00f6f0).
- `Form::holds_secrets`: ENTRY, NOTE and `PASSPHRASE_FORM` (0xF0) (`faraday/faraday-core/src/vault/area.rs:~2313-2315`, `~2320`). `focus_is_secret` (`~3028-3038`): passphrase, dice, prompt fields and entry/note fields are secret; name, label and search are not.
- Leaving an item page (`tidy_shown`, `faraday/faraday-core/src/vault/area.rs:621-634`): when the page or selected record changes, `hide_item_secrets` drops shown, words and paperkey (the TOTP `code` is kept); `sign_shown` is cleared when not on the signing page or the page is not on screen.
- `drop_shown` wipes SeedQR, words, paperkey, code and shown (`faraday/faraday-core/src/vault/area.rs:~2909-2915`). `open_item` (`~404-411`) clears form, saving, prompt and back_to (not the passphrase). `edit` (`~1751-1761`) clears `code`/`codes` and drops the vault's `Read`. `close_item` (`faraday/faraday-core/src/vault/act_state.rs:~140-149`) clears form, prompt, focus, Secure Boot images and sign state. `sb_reset` (`faraday/faraday-core/src/vault/area.rs:~880-883`) clears `sb_sign`, `sb_images`.
- `left_contents` drops the one-line prompt when Vault contents is left, except a wallet's missing passphrase (`Purpose::ForWallet`) (`faraday/faraday-core/src/vault/act_state.rs:~105-114`). The typed passphrase is dropped when its prompt is left (fix 2862380b9).
- Load: `LoadSheet` (`faraday/faraday-core/src/vault/load.rs:~27-53`) in `app.vaults.load`: `name`, `boot`, `signer`, `wallets_before`, `ticked`, `choice`, `passphrases: BTreeMap<usize, Vec<String>>` (labels), `auto`. `PassSeeds` (`~115-123`): `wallet`, `missing` (fingerprints), `picked`. The typed passphrase is `vaults.prompt.pass` (`PassField`); `pass_seed_try` copies it into a `Text` for `load_key_with_passphrase` (`faraday/faraday-core/src/vault/mod.rs:~1077`, `~3831`). `KeysJob` holds passphrase words while the job runs.
- Copy: `CopyTo` (`faraday/faraday-core/src/vault/copy.rs:~44-68`, `vaults.state.copy_to`): `from`, `record`, `version`, `rows`, `ask`, `mv`, `from_name`, `unread`, `keeps`. `CopyWait` (`~423-446`, `copy_wait`): item by place, `version`, `mv`, `to`, `new`, `view`. Both hold labels and field numbers only. `SaveHold` (`faraday/faraday-core/src/vault/related.rs:~11-23`): `pending: Vec<(Staged, Text)>`, `moved: Option<(from, at, n, version)>`; lives as long as the dialog; `Staged` may hold key material.
- `settle` (`faraday/faraday-core/src/vault/copy.rs:~392-416`) drops `copy_wait` when the original is gone or changed or the awaited screen or sheet is no longer up (a new vault needs `Screen::CreateVault` or `Work::Create`; an unlock needs `Screen::Unlock`, `Sheet::OlderCopy` or `Work::Unlock`); it drops `copy_to` when its sheet is gone (`~411-414`). `moved` and `moved_subjects` are cleared in `close` and `close_all`.
- Keep choices: `KeepSave` (`faraday/faraday-core/src/vault/keep.rs:~86-98`): `asks`, `left`, `then`, `into`; `Ask` (`~74-82`); `Left` per flow (`~55-61`); fingerprints, labels and field numbers only; `settle` drops `keep_save` when the sheet is gone (`~306-312`).
- Key file: `vaults.state.more`, `key_outbox: Vec<(VaultId, Text)>` (pending `.keyx` names, dropped with the vault, `faraday/faraday-core/src/vault/more.rs:~98-109`, `~136-143`), `key_chosen: Option<(VaultId, Text)>` (cleared by `settle` when the vault is not open and on `sealed`, `~89-93`, `~359-364`), `key_pick`, `key_for_create`, `key_menu`. - KeePass export: the `written` bytes are held until the check.
- Save to a stick: `StickSave.files[..].made` holds only a wallet's public files, made when the popup opens, and is empty for a seed's (`faraday/faraday-core/src/vault/out.rs:25-37`). - At a lock `lock_secrets_off_screen` calls `vaults.hide_secrets()` (item secrets and `sign_shown`; the TOTP `code` is taken and put back, `faraday/faraday-core/src/vault/area.rs:640-651`); the seal's end runs `close_all` (drops shown, seedqr, words, paperkey, code, codes, moved, open, stuck, `store.clear()`, search reset) and sets `form`, `load`, `pass_seeds` to None (see `vault-seal`). - `save_hold` is dropped after any press or tick once `Sheet::SaveAlso` is not up (`vault_save_also_settle`, `faraday/faraday-core/src/vault/mod.rs:4774-4781`, called at `1158-1165`). `older` is dropped once its vault is not open (`vault_older_settle`, `faraday/faraday-core/src/backups/mod.rs:4205-4216`). ## Rules and refusals
- After a copy or move's target vault is unlocked: a changed original, a sheet standing, or a refusal by the judge each toast "refused" with the reason; a target or origin no longer open, or a record that cannot be staged, ends with no message and the wait gone (faraday/faraday-core/src/vault/copy.rs:566-640).
- Memory records written at a seal drop older ones with no message: nonce records of the replaced transactions, the oldest nonce records past the entry cap (never those put in this call), and, only while the vault is past its ceiling, the oldest nonce record before any amounts record (faraday/faraday-core/src/vault/area.rs:1640-1720).
- Save to a stick for a key record writes the words and SeedQR picture from the record at the saved index of the vault `current` names when the write is pressed (faraday/faraday-core/src/vault/mod.rs:4548-4600; vault/out.rs:62-70).

- Secret view: `shown_here` refuses when a form, prompt, saving, signing or Secure Boot images are on; secret fields show only on the selected record's item page (`faraday/faraday-core/src/vault/area.rs:~1258-1271`). `vault_secrets_on_page` shows secrets only on the item page with no sheet over it and not while `devices.holding()` (`faraday/faraday-core/src/vault/mod.rs:~4252`).
- `toggle_shown` (`faraday/faraday-core/src/vault/area.rs:~674-714`): only KEY (words) or GPG (paperkey) give content; other bits are stored with no content. `toggle_seedqr` (`~720-752`): KEY only, English only, the encode must succeed. `form_part` maps secret fields to reveal parts only for ENTRY (password, notes, TOTP) and NOTE. `Described` is parsed only for WALLET, PLAN, WALLET_SHARE (`~1882-1888`).
- Eye bitmask (`Rows::secret`, `faraday/faraday-core/src/vault/screen.rs:2889`): `1u64 << secret_id.min(63)`, so the 64th and later secrets on a page share one eye bit.
