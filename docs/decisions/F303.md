# F303 The navigation shows state as badges in the warning colour, orange (2026-11-21)

**Kind:** Record
**Status:** Active
**Area:** design
**Held by:** tests

*Differs from Material 3, where a badge is error-coloured.*

**Why.** The owner (2026-11-21): the red of an error badge was harsh for what only waits (files to look at, wallets with something to do, vaults open), and four kinds of state mark in the navigation was too busy.

**Decision** (owner, 2026-11-21).

1. The navigation shows state only as badges, on the sidebar and the rail alike: Files, the files the Inbox holds (or a dot while a stick waits); Wallets, how many wallets need something now; Vaults, how many are open. None while the number is zero. The sidebar's flow-in-progress rows (F41) stay: they are rows, not marks.
2. A badge is filled in the warning role (orange, `docs/THEMES.md` §5) with its label in on-warning, the count badge and the dot alike, so it reads as something waiting, softer than error red. Replaced by F311 (Bitcoin orange, white label).
3. Home carries no chip row (F302): what was in it, flows in progress and files waiting to be written, are the first rows of Home's box.
4. The box is as wide as Home's top row, not the search bar alone (F314 amends its width).
