# F302 Home states what is going on in one row, and lists only what needs something (2026-11-21)

**Kind:** Record
**Status:** Active
**Area:** design
**Held by:** tests

**Why.** Home repeated Wallets' list, a tile for every wallet and key,
and so pushed what needs doing below the first screen. What is going on
(a vault open, a spend under way, files waiting) stood in three places: a
card, the box of what is loaded and the chips over the page.

**Decision** (owner, 2026-11-21; `docs/HOME.md` §1 to §5).

- On the wide layout and the rail's windows Home runs: the search bar, the
  lead at the page's full width, the three first actions, one row of
  assist chips for what is going on (each vault open, each flow in
  progress, files waiting to be written; not drawn while empty), Wallets,
  Keys.
- Wallets are list rows only for a wallet that needs something now
  (signatures under way, a PSBT to sign, not backed up), then one row
  "All wallets ({n})" opening Wallets, and the Backups row. Keys are rows
  only for a key no wallet uses, offering a wallet from it, then "All keys
  ({n})" opening Explore. A key no wallet uses is therefore no lead on the
  wide layout.
- F41 still binds: the chips over every page beside the rail and the flow
  rows under each tab in the sidebar stay; Home's row is added beside
  them.
- The Pi's menu and the phone-size window keep their own Homes; their box
  of what is loaded takes the same idea (a vault open in its first line, a
  name never cut short while room is left beside it, wallets that need
  nothing folded into "+ {n} more").

Follows Material 3 Chips (assist chips) and Lists (two-line items).
