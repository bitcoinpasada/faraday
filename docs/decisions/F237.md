# F237 Transfer calls Read the words and does not offer it; the screens_not count is 23 (2026-11-10)

**Kind:** Record
**Status:** Active
**Area:** crypto
**Held by:** crypto.action-covered

*Amends F164 (the manifest's screens_not count).*

**Why.** Send text on Transfer (F236) refuses seed words: it looks each
word of the text up in the BIP-39 lists, as they are and without their
accents, through `faraday_bip::bip39::fold`, a root of the words-read
action (Read the words). `docs/crypto/gen_how.py`'s screens check then
finds Transfer calling words-read's root without offering the action.
Transfer reads no seed, so listing it in the action's `screens` would give
its Learn tabs the seed words' page for nothing. The entries that F164
named have fallen to 22 since.

**Decision** (owner, 2026-11-10). words-read has a `screens_not` entry for
Transfer, and `tools/lint-crypto.counts` reads `screens_not 23`.
