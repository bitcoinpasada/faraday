# F264 The Argon QR Vault and its test tool live in their own repository; Faraday keeps nothing for them but `faraday-window`'s default feature (2026-11-14)

**Kind:** Record
**Status:** Active
**Area:** standards
**Held by:** standards.out-of-app

*Replaces F245 (the Argon QR Vault is built as a test tool in `aqrv/`) and F249 (its specification and vectors live in their own repository, the reference implementation stays here).*

**Why.** The test tool's library, command line and desktop app were kept
in this repository only to share its build. They cost Faraday a strings
feature, four workspace members, five fuzz targets, a pinned copy of the
vectors and a set of lints whose only job was to keep the tool out of the
apps. The tool now builds in its own repository against Faraday's crates
at a pinned commit, so none of that is needed here.

**Decision** (owner, 2026-11-14).

1. **Its own repository.** The Argon QR Vault's specification, its test
   vectors and their generator, and the test tool (the library, the
   command line `aqrv`, the desktop app and their fuzz targets) live in
   `https://github.com/bitcoinpasada/aqrv`. Faraday holds none of its
   code, vectors or strings.
2. **Faraday's crates by a pinned commit.** The tool uses Faraday's
   crates as git dependencies at one named commit of this repository.
   Faraday keeps nothing for it beyond what any other program could use:
   `faraday-window`'s default `faraday` feature, which a program turns
   off to use the window without the Faraday app.
3. **Not in the apps.** The format is Faraday's own construction with no
   outside review, so STANDARDS §0 keeps it out of every app. Bringing it
   in is a new decision, made after an outside review is recorded
   (`docs/AUDIT-SUBMISSIONS.md`).
