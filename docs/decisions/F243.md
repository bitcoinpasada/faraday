# F243 One targeted check may run on GitHub Actions, started by hand (2026-11-11)

**Kind:** Record
**Status:** Active
**Area:** repository
**Held by:** repo.ci-check

*Amends F183 (2026-11-11): a third workflow, started by hand, runs one crate's tests or one lint recipe; everything else F183 says of what GitHub Actions may do holds for it.*

**Why.** The full check is twenty-two jobs and runs as one. A builder
changing one crate needs only that crate's tests or one lint recipe, and
GitHub's runners sit idle most hours, free for a public repository.

**Decision** (owner, 2026-11-11).

1. **A third workflow**, `.github/workflows/targeted.yml`, started by hand
   (`workflow_dispatch`) on any branch. It runs one job: either `cargo
   nextest run --locked -p <crate> -E <filter>` (the filter optional,
   `all()` by default), or one recipe from a fixed list of the justfile's
   lint recipes (`lint-clippy`, `lint-deps`, `lint-repo`, `lint-macos`,
   `lint-touch-targets`, `lint-op-cost`), chosen by a `choice` input that
   also has `none` for a run of tests only. It never starts by itself, and
   it does not replace `just`: the check stays the whole of it.
2. **Inputs are checked before use.** The crate matches
   `^[a-z0-9_-]{1,64}$` and is a member of the workspace (`cargo metadata
   --no-deps`); the filter matches
   `^[A-Za-z0-9_:/^$().|&!= ~*-]{0,200}$`. Inputs reach the shell only
   through `env:`, never written into a `run:` line.
3. **F183's limits hold.** Its token only reads (`permissions: contents:
   read`); it uses no secrets; the checkout keeps no credentials; it uses
   only GitHub's own actions (`actions/*`), pinned by commit, on GitHub's
   standard runners. It builds nothing for release. It reuses
   `.github/actions/setup` and reads the same cache as the check under
   F212's rules; it saves nothing to the cache.
4. **One run a branch.** Its concurrency group is the branch, and a new
   run cancels the one before it.
