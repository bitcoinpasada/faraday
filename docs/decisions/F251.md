# F251 The check does not type-check the Starter's macOS code while macOS is paused (2026-11-12)

**Kind:** Record
**Status:** Active
**Area:** repository
**Held by:** repo.ci-check

*Amends F183 (2026-11-12): `lint-macos` is no longer one of the parts of `just lint` its second point runs; everything else it says holds.*

**Why.** Faraday is not being developed for macOS. Type-checking the
Starter's macOS code for both Mac targets in every check costs a job and
the two targets' install, and holds back work for a platform no one is
building or testing.

**Decision** (owner, 2026-11-12).

1. **Out of the check.** `just lint` and the check's lint parts no longer
   run `lint-macos`, the setup action no longer installs the Mac targets,
   and the targeted check of F243 does not offer it.
2. **Kept, by hand.** `just lint-macos` and `tools/check-macos.sh` stay,
   so the macOS code can still be checked by anyone who changes it.
3. **Back with macOS.** When macOS work starts again, a new decision puts
   the type-check back in the check.
