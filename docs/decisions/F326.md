# F326 Faraday Demo has a dev build, and only it carries the handwriting reader and ACE (2026-11-23)

**Kind:** Record
**Status:** Active
**Area:** release
**Held by:** review

*Not built.*

*Amends F5: the desktop build had no dev variant.*

**Why.** Faraday Demo runs on a computer with a webcam and holds test data,
so the two features of F325 can be tried there.

**Decision** (owner, 2026-11-23).

1. **Faraday Demo's dev build** carries the features `handwriting` and
   `ace`. It is never published, and names itself a dev build as F5's table
   does. It has no console or login of its own.
2. **The app's dev image is unchanged** (a console and a serial login) and
   carries neither feature.
3. **The modes are Faraday Demo's:** Practice, Testnet, Signet and Regtest.
   Practice takes the public samples only (`docs/MODES.md` §4 and §5); any
   other test seed is read on a test network.
4. **What this leaves untried:** a device's camera, panel and speed, and a
   lock on a device.
