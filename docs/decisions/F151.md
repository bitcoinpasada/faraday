# F151 A review rule a change triggers is attested in the commit (2026-10-28)

**Kind:** Record
**Status:** Active
**Area:** repository
**Held by:** impact.registry

*Amends F149 (2026-10-28), point 3: a review rule is met by a `Reviewed:` trailer; before, `impact.py check` listed it and never failed.*

**Why.** F149 left the rules that only a person can judge (a string
that explains, a name in a document that should not be there, a
personal detail in a commit) as `review` rules: `check` listed them and
passed. A rule held only by a list that nobody has to read is held by
memory, and a judgement could be skipped without anyone noticing. The
owner wants each one attested where it can be seen afterwards, in the
commit that triggered it.

**Decision** (owner, 2026-10-28; `docs/IMPACT.md` §1.3, §2.2, §3).

1. **The trailer.** A `review` rule of the registry that a change
   triggers is met only when a commit in the checked range, or the
   `--message` file, carries `Reviewed: <rule>`. Unmet, `check` prints
   `impact: unreviewed <rule>: <paths>; add "Reviewed: <rule>" once
   checked` and fails like an unmet pair.
2. **Several rules in one trailer.** `Reviewed: strings.plain,
   crypto.kept-values` names both. A `Reviewed:` naming a rule
   that is not triggered, is not a review rule or does not exist is a
   note, not a failure.
3. **Waiver.** `Impact-skip: <rule>: <reason>` still waives a review
   rule, as it does a pair.
4. **Extra rules are exempt.** A rule from a `FARADAY_IMPACT_EXTRA`
   file is listed and never fails: the repository does not know it
   (F149, point 5).
5. **Plan says so.** `plan` lists the review rules a change touches
   under a heading saying each needs a `Reviewed:` line.
6. **Standing rules are not attested.** A review rule whose only
   trigger is every file (`**`, exclusions aside), such as no personal
   information or the build machine never named, applies to every
   change; a line on every commit would be written without being read.
   It is listed and never fails; the push hook or a check of its own
   holds it.

The trailer is the author's word that the judgement was made; no script
can check it.

**Where:** `tools/impact.py` (`evaluate`, `plan`, the self-test);
`docs/IMPACT.md` §1.3, §2.2, §3, §13; `CLAUDE.md`.
