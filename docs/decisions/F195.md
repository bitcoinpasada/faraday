# F195 A secret the person chose to show is worked out once and held while shown (2026-11-03)

**Kind:** Record
**Status:** Active
**Area:** speed
**Held by:** speed.shown-secret-held

*Amends `docs/SPEED.md` §2 rule 1 ("Nothing secret is kept ... not even for a frame") and the `Allowed::SecretShown` entry of §3.3.*

**Why.** The earlier rule kept nothing secret, not even for a frame, so
every secret the person had opened was worked out again on each frame it
was drawn. The constant-time word lookup made that a scan of the whole
word list for each word on each frame of the seed reveal. A person who
has chosen to show the words has accepted that they are on the screen
and in memory; there is nothing to protect by working them out again, and
the repeated work only costs time.

**Decision** (owner, 2026-11-03; `docs/SPEED.md` §2 rule 1, §3.3, §7,
§8.3).

1. **A secret the person opens to see or copy by hand is worked out once
   when it is shown and held** with the screen's state, in a holder that
   wipes on drop: a seed's words, its SeedQR numbers and grid, a BIP-85
   child, a vault key record's words, a GPG paperkey, a vault entry's
   TOTP code.
2. **It is dropped and wiped the moment it is hidden, when the person
   leaves the page, and at a lock**, and drawing it stops.
3. **Drawing it again works out nothing.** A TOTP code is worked out once
   for each period, as it changes with the clock.
4. **Everything else kept to save work stays public** (`docs/SPEED.md` §2
   rule 1 otherwise unchanged): a fingerprint, a checksum, an account key,
   a file name, a count or a yes/no about public data.
5. **The budget tests draw each shown secret twice**, and the second
   frame works out nothing.
6. **A fix that makes a function reached by drawing do more work** (as a
   constant-time fix does) counts it as costly work: it takes `c:
   &Compute`, its doc's first line says "Costs ...", and it is counted, so
   the budget tests see it.
