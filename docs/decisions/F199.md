# F199 A field a signer adds is stated when its content can be checked in full, and is a finding otherwise (2026-11-03)

**Kind:** Record
**Status:** Active
**Area:** security
**Held by:** keys.signer-added-fields

**Why.** The signer check (`docs/SIGNER-CHECK.md`) made every field added
on the returned PSBT a finding. Major signing software adds fields beside
its signatures: Bitcoin Core adds scripts, UTXOs and tap fields for what
it can solve, and Passport adds the sighash type. A check that refuses
all of it refuses what a person's own wallet software returns. A field
whose whole content is fixed by what was sent carries no room beyond its
presence.

**Decision** (owner, 2026-11-03: follow what major wallets do, scoped to
added fields whose content can be checked; fail closed for the rest).

1. **Stated, at Info.** A field absent on Sent and present on Returned,
   under a key of exactly one byte (the type byte), is stated and not a
   finding when its content is checked in full, each anchored only to the
   unchanged transaction or to Sent, never to Returned's own copy of
   anything: a witness script or redeem script that hashes to the script
   of the output or of the spent output; a witness UTXO equal to the
   output Sent's non-witness UTXO holds; a non-witness UTXO with the
   input's previous txid and no witness in any of its inputs; an input's
   internal key and merkle root that recompute the spent output's key; a
   sighash type equal to that of every signature on the input, with at
   least one. The spent output's script comes from Sent's UTXO fields
   only; with none, there is no anchor.
2. **Everything else stays a finding:** tap trees, leaf scripts, key
   origins, extended public keys, preimages, an output's internal key,
   proprietary and unknown fields, and any field not matching its anchor.
   A removal stays Caution.
3. **The words** of an Info line never say a field was "changed" or is
   "mine": whether a signer adds such a field is itself a signal (Core
   adds a script only to an output it can solve). The residual room is a
   presence bit and the order of a map.
4. **A MuSig2 pair is read in the three aggregate forms** the crate reads
   (root aggregate, derived aggregate, output key), anchored to Sent.

The rule is `keys.signer-added-fields` in `tools/impact.toml`.
