# F85 Text size: Standard, Large, Larger, and the layout steps down for it (2026-10-23)

**Kind:** Record
**Status:** Active
**Area:** design

**Why.** Text is drawn at one size for each layout. A person who needs
it larger has only Display scale, which magnifies everything and keeps
the layout, so on a desktop window the page is cut off at 200 % and on
the panel there is nothing larger to step to. Text that is larger has
to be given room by the layout, not just drawn larger.

**Decision** (owner, 2026-10-23; the spec is `docs/TEXT-SIZE.md`,
planned after the structure pass).

- Settings › Appearance gains Text size: Standard, Large, Larger, ×1.0,
  ×1.2 and ×1.4 on every text size, named in `tokens.rs`. It is kept as
  the theme is: a `text=` line in the kept set and in the stick's
  settings file.
- Keyboards, the dice pad, QR codes and SeedQR, firmware sketches and
  icons keep their sizes. A one-line slot that cannot grow fits its text
  down, never below Standard. A row or button grows to its text, so
  touch targets grow with it.
- The one-column decision counts the text factor and the Display scale:
  a window takes the one-column layout where it would be that many times
  too small for Standard's wide layout. The small panel wraps and
  scrolls.
- The Starter has the same setting, and its held app follows it.
- Every screen fits at Larger at every size: snapshot tours render at
  Larger, and a test fails on text cut at its right edge or drawn over
  other text.
- A row's icon grows with its label; Display scale stays beside Text
  size.
- Faraday Desktop keeps the theme and Text size in memory only, until
  it quits. The Starter's Text size is on its About page and is stored
  only once the Starter is installed, in a file Uninstall removes.
