# F214 A Spec holds the design and whether it is built, and carries no work list (2026-11-05)

**Kind:** Record
**Status:** Active
**Area:** repository
**Held by:** docs.spec-no-work-list

**Why.** A Spec's table of work, with its labels, sizes and who does what, is
a plan for the people building Faraday today, and it goes out of date as they
work. Anyone reading the repository to understand a feature needs what the
feature is and whether it is built, and neither needs nor can check the rest.

**Decision** (owner, 2026-11-05).

1. **What a Spec holds.** What a feature is, how it is designed, and whether
   it is built. Its `**Open:**` line says what is not built, in plain words
   ("not built yet"), never by a work label.
2. **What it does not hold.** No table of work, no labels for pieces of work,
   no sizes, estimates or choice of who does a piece.
3. **What stays.** Design detail such as what must come first and which files
   change stays as plain text, in terms of the order of building, where it
   matters to anyone building Faraday.
4. **Where the old tables go.** Each moves as it stood to
   `docs/history/<NAME>-LOG.md`; a section that held only the table keeps its
   heading with the one line naming where it went, so a cited section number
   still resolves. Decisions are records and keep the labels they were written
   with; the log says what each meant.
