# F252 A shell can no longer fix a session's network (2026-11-12)

**Kind:** Record
**Status:** Active
**Area:** platforms
**Held by:** review

*Amends F20 (2026-11-12): its point that a shell can fix the session's network, which the website's demo used, is withdrawn; everything else it says holds as F81 amended it.*

**Why.** A fixed network was for the website's demo, which kept itself
on mainnet so that it took only public seeds. The website no longer
carries that demo, and no shell fixed a network after it: the code had
no caller but its own tests.

**Decision** (2026-11-12).

1. **Gone.** `Keys::fix_network`, the refusal it gave and the mode
   sheet's dimmed rows for a fixed network are taken out; every row of
   the mode sheet can be chosen.
2. **The network's guards stay.** A session holding a key or a wallet
   still moves to no network of another kind, and Faraday Demo still
   offers no Mainnet (F81); a wallet or a PSBT on another network is
   refused as before.
