# F165 The stick and the Pi read Faraday Offline (2026-10-26)

**Kind:** Record
**Status:** Active
**Area:** design
**Held by:** tests

**Why.** Faraday Demo's header reads FARADAY DEMO and the Starter's
FARADAY STARTER (F16), while the stick and the Pi showed FARADAY alone,
so the one app that holds keys was the one whose name said least about
it, and it read as unfinished beside the other two.

**Decision** (owner, 2026-10-26). The device's name, on the stick and on
the Pi, is FARADAY OFFLINE: OFFLINE after FARADAY as DEMO and STARTER
are, in the same Archivo Expanded (wdth 125) at weight 400, in the grey
of secondary text (`faraday-ui/assets/wordmark-suffix.txt`,
`NameSuffix::Offline`). On the expanded rail's head and on Home's top bar
it stands on one line where it fits; on the Pi's panel it stands on one
line where no mode pill is beside it and, beside the mode pill, OFFLINE
under FARADAY as DEMO stands on a narrow window (`Ui::wordmark_fitted`,
`docs/LAYOUT.md` §3). The boot logo, the mark alone, is unchanged.
