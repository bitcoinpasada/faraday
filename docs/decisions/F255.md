# F255 Check takes Create a vault's place on Home and is a place of its own in the sidebar (2026-11-14)

**Kind:** Record
**Status:** Amended by F275, F277
**Area:** design
**Held by:** review

*Amended by the owner, 2026-11-18: on the Pi's Home menu Wallets is the first tile and Check the second.*

*Amended by F275 (2026-11-16): Home's Check tile is only where the navigation has no Check.*

*Amended by F277 (2026-11-16): point 3, the Check screen is tiles in the grid Tools uses, no longer a list.*

*Amends F235 (2026-11-14): the navigation rail and the expanded rail carry six destinations, Check right under Home; the navigation bar keeps its five, so Tools still never gives way on it.*

**Why.** A common reason to keep Faraday on a second, offline computer is
to check what a hardware wallet says: that its seed makes the wallet the
wallet app shows, that an address on its screen is the wallet's, that a
transaction is what it seems before signing, that what it signed is what
it was sent and that its signatures hide nothing. Faraday does each of
these, but in Tools, among some fifty tiles grouped by kind, where a person
with a hardware wallet in hand has to know each tool's name to find it.
Home's fourth tile, Create a vault (Vaults once a vault exists), opens a
place the sidebar already has a row for.

**Decision** (owner, 2026-11-14; `docs/DESIGN.md` §5, `Check`;
`docs/LAYOUT.md` §3, §4).

1. **A place of its own.** **Check** is a destination, right under Home
   on the expanded rail and on the navigation rail, its icon a shield
   with a tick. On the Pi's Home menu it is the second button, after Wallets. On the
   navigation bar of a compact window it is not a destination: Material 3
   gives the bar three to five, and the five there stay; Home's Check tile
   is its way in there.
2. **Home's fourth tile is Check, always.** **Check a hardware wallet**,
   "Its seed, addresses and signatures", in place of Create a vault or
   Vaults, which is reached from the sidebar, the rail, the bar and the
   Pi's Home menu. The lead tile and its jobs, Unlock {name} and Write
   {name} to a stick among them, are unchanged; Backups still follows
   once a wallet is known.
3. **The Check screen is a list** (Material 3 Lists): each row a label and
   one line saying what the person needs in hand, opening the tool that
   does it. The screen's name is the verb and each row its object, so a
   row reads "An address on its screen", and the tool it opens keeps its
   own name ("Check an address"). The rows and their order are DESIGN
   §5's.
4. **Tools stays the master list.** Every feature is in Tools
   (`faraday/faraday-core/src/catalog.rs`); Check is a second way in to
   some of them, never the only one, and a check added to Check is added
   to Tools too.

**Against Material.** Nothing: the rails take up to seven destinations,
the bar keeps its five, and the screen is a plain list with subheaders.
