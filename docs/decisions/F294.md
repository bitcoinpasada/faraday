# F294 The QR vault is removed from Faraday; a code or file made as one is refused as an unknown code (2026-11-19)

**Kind:** Record
**Status:** Active
**Area:** security
**Held by:** review

*Amends F190 (2026-11-19): points 5 and 9's QR size go, and points 6, 7, 8 and 11 hold for the file vault only. Amends F160 and F193 (2026-11-19): the F79 area `vault` has no QR vault to check. Withdraws F211 and F226 (2026-11-19).*

**Why.** The owner removes the QR vault (owner, 2026-11-19). A seed's
encrypted code is the Krux code (KEF, F219), which a Krux device reads
and writes; a vault a person keeps is the KDBX 4 file (F190). The QR
vault was a third form beside them that only Faraday made, and it kept
an OpenPGP message format, the OCB dependency, a cross-check area and
its own outside sealer in the app and its checks for it alone.

**Decision** (owner, 2026-11-19).

1. **Removed from the apps.** The QR vault tool in Tools (Make and
   Open), Save as a QR vault on a file vault's item, and the reading of
   a QR vault wherever a SeedQR is scanned or a `.pgp` file is imported
   go, with their strings, guide page, tour and tests.
2. **An old one is an unknown code** (owner, 2026-11-19). A QR vault
   made before this, scanned or imported, is refused as any code or
   file Faraday does not read is refused. No screen, string, guide page
   or page of the website names the QR vault or says how to open one.
3. **Removed from the libraries and checks.** What only the QR vault
   used goes: its holder and reveals in `faraday-keys`, its contents in
   `faraday-vault`, the OpenPGP message in `faraday-pgp` (the GPG key's
   certificate, paperkey and armor stay), the `ocb3` dependency, its
   fuzz target and sample, the F79 area `qrvault` with rPGP as its
   sealer, and its vectors.
4. **What follows elsewhere.** F190's KDBX 4 vault is unchanged. F211
   (the QR vault's judges) and F226 (the QR vault made in Tools) are
   withdrawn. The Argon Compact Envelope (F264), a separate format in its own
   repository, stays.
