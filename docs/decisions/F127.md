# F127 FROST removed from the repository until its standards are published (2026-10-26)

**Kind:** Record
**Status:** Active
**Area:** wallets

**Why.** FROST threshold signing rests on BIP 445, and its key
generation on ChillDKG; both are drafts. Faraday's trusted dealer and its
way of signing across places were Faraday's own constructions, not
reviewed. F109 compiled FROST out of every shipped app and kept its code
in the repository, built and tested. Code that stays in the repository
is still read, built and audited as if it were live. The owner removes
it, so that it is neither shipped nor audited as live code. FROST comes
back only as a new implementation of the published standards, with each
signer drawing its own nonce at its own place, not as this code adapted.

**Decision** (owner, 2026-10-26).

- **What goes.** Everything that existed only for FROST: the FROST
  arithmetic and the threshold record in `core/faraday-bip`, the
  threshold signing, its `osk` PSBT records and the carry file in
  `core/faraday-psbt`, the shares and the dealer in `faraday-keys`, the
  app's FROST code, strings, Learn page, sample, test kit files and tour
  stops, the cross-check's FROST area, the BIP 445 reference and vectors,
  the threshold fixtures and the fuzz target for the carry file. The
  cargo feature `unreleased` goes with it: nothing else was behind it.
- **What stays.** MuSig2 (BIP 327) entirely, and F109's MuSig2 rule: no
  MuSig2 secret nonce is kept past the session it was drawn in. The
  vault's record type 9 (a signing round) keeps its number and layout in
  `faraday-vault`; the app writes none and reads none into a spend.
- **The shipped app does what it did.** A threshold wallet's record is
  not read as a wallet. A carry file is a file Faraday does not read and
  opens no spend. A taproot key-path input carrying proprietary records
  under Faraday's own identifier `osk` is blocked, not signed: this build
  reads no such record (`faraday_psbt::WarningKind::UnreadRecords`). The
  number a backup flow kept across a lock writes for its wallet kind does
  not change (`faraday_core::create::NewKind::code`).
- **Coming back** is the owner's decision, recorded in a new decision:
  once BIP 445 and a key-generation standard are published, as a new
  implementation of them.

**Amends.** F109: its FROST part.
