# F116 Faraday's scope: an offline signer and keeper of keys, Bitcoin first (2026-10-25)

**Kind:** Record
**Status:** Active
**Area:** scope

**Why.** STANDARDS §0 said Faraday is "an offline Bitcoin signer and its
keys' keeper" and that a feature outside that is not taken on. The app
already signs with an OpenPGP key (F32), keeps TOTP secrets in a vault
and makes Secure Boot keys, so the rule as written did not describe it
(owner, 2026-10-25).

**Decision.** Faraday is an offline signer and keeper of keys: a person's
Bitcoin wallets and their backups first, and the other keys a person
keeps offline beside them (an OpenPGP key, TOTP secrets, Secure Boot
keys). A new kind of key or signature comes in on the owner's word,
recorded here in DECISIONS; STANDARDS §0.1 names what is left out (SSH
signatures and an SSH CA, minisign and signify, an X.509 certificate
authority). Every rule of STANDARDS §0 applies to whatever is in scope.
