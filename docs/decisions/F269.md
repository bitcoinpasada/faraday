# F269 costs-lint no longer holds the Costs doc line or its table of mint sites (2026-11-14)

**Kind:** Record
**Status:** Active
**Area:** speed
**Held by:** compute.new-mint

*Narrows F69 (2026-11-14): a costly function no longer has to say "Costs …" on its doc's first line, and `tools/costs-lint` no longer lists the places that mint a token; everything else F69 says holds.*

**Why.** `tools/costs-lint` kept its own table of the places allowed to
mint a `Compute` token, and checked the first line of each costly
function's doc. Clippy's `disallowed-methods`, with an
`#[expect(reason)]` at each mint, holds the same set of places in the
compiler's own check, so the table was a second list to keep in step.

**Decision.**

- A mint of the token is held by clippy, an `#[expect]` with its reason at
  each one. `costs-lint` keeps what clippy cannot: its rules on counted
  work taking `&Compute`, `Compute::unchecked` and the manifests, and its
  rules 3 and 4.
- The "Costs …" first line is not required. A stated cost still says how
  it was measured (F238).
- Test code in `faraday-keys`, `faraday-vault`, `faraday-pgp` and
  `faraday-kef` is not checked by clippy for mints (`docs/COMPUTE.md` §7);
  with the table gone, a mint there is held by review only.
