# F99 APK signing is removed (2026-10-23)

**Kind:** Record
**Status:** Active
**Area:** keys

**Why.** APK signing served the phone companion, which was dropped (F34),
and F59 had already switched it off in the app. No vault holds an APK
signing key. What stayed was a crate, a vault record type, a backup-flow
kind, a Tools tile, a Files row, a Learn page and a spec, all unused.

**Decision** (owner, 2026-10-23).

- Everything APK is removed: the `faraday-apk` crate, the key kind in
  `faraday-keys`, the backup flow's APK key, its screens, strings and
  actions, the budget entries, the fuzz target, the vectors, the Learn
  page, the Files row and the Tools tile. The APK spec moved to
  `docs/history/APK-SIGNING.md`; F25 and F59 move to `docs/history/decisions/`; F31, F34
  and `docs/LARGE-FILES.md` lose their APK parts.
- The vault's format and encryption do not change. Record type 12, once
  an APK signing key, is retired: no build knows it, and a slot holding
  one is refused like any unknown record type (`docs/VAULT.md` §7). The
  number is not used again. Nothing is kept to read or migrate one.
- The vault vectors are written without the type 12 record; every other
  record is as it was.
- `faraday-keys` had no named reveal for the APK key (F70's eleven are
  unchanged): its private key left only as signatures, inside the
  crate. Its secret field is no longer in `SECRET_FIELDS`.
