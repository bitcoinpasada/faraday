# F91 The Starter is laid out to Material 3's layout and navigation rules (2026-10-23)

**Kind:** Record
**Status:** Active
**Area:** design

**Why.** The Starter's Home is one column of wide rows of equal weight:
the next step, the tools and the one-off actions all read alike, and a
person has to read every row to find their way. A published standard
for layout and navigation gives a tested answer to where things go at
each window width, instead of one invented here.

**Decision** (owner, 2026-10-22: Material 3, its layout and navigation
only; the spec is `docs/STARTER.md` §3.1 and §3.1d, planned).

- The Starter uses Material 3's window size classes: compact under
  600 dp, medium from 600, expanded from 840, read from the width
  divided by the text size factor (F85). The page is laid out again at
  each class, never scaled.
- Four destinations, Home, Make, Tools and Learn, each one level deep,
  on a navigation rail on medium and expanded windows and a navigation
  bar at the foot on compact. A page inside a task shows neither.
- A top app bar with the wordmark, Install or Update while it applies,
  and a ⋮ menu for what is not a destination: About, Uninstall, Remove
  the boot entry.
- Home leads with the This computer card holding the checklist and the
  screen's one primary button (D12 kept), then cards about this
  computer in a responsive grid. One primary action a screen.
- Margins, gutters and the bars' sizes are Material's, on its 4 dp
  grid, as named tokens.
- The look stays Faraday's own: `faraday-ui`'s components, DESIGN's
  tokens and themes. No Material colours, shapes or typefaces.
- Faraday Desktop and the device keep DESIGN §3's two layouts and the
  sidebar; Material 3 there would be a decision of its own.
