# F198 The download page has one Pi tile (2026-11-03)

**Kind:** Record
**Status:** Active
**Area:** release
**Held by:** review

*Amends F147 (2026-11-03): the Pi is one piece of hardware on the download page, whatever its screen. Amends F186 (2026-11-03): one tile leads to the one Pi image, not one for each screen.*

**Why.** With one Pi image, a tile for each Pi screen offers the same
file twice and looks like two downloads. A person coming to the page is
getting the stick, the Pi image or the Starter.

**Decision (owner).**

1. The download page has one tile for the PC and one for the Pi, which
   asks nothing about screens.
2. The hardware page sets out the setups, the Pi's screens among them.
3. Each screen keeps its own row and state in `docs/HARDWARE.md` §1.
   The Pi tile reads Tested only when the Pi image's state there does.

`docs/IMAGES.md` §7 says what the pages show.
