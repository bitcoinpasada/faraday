# F261 KEF writes versions 20 and 5 and reads all twelve (2026-11-14)

**Kind:** Record
**Status:** Active
**Area:** crypto
**Held by:** crypto.kef-claim, crypto.kef-claim-code

*Amends F219 (KEF enters Faraday, all twelve versions read and written): writing is version 20 and version 5 only.*

**Why.** Ten of the twelve versions exist for older Krux codes. A person
making a new code needs the strongest (20, GCM with a check Krux reads)
and the smallest (5, for a 12 or 24 word code that fits a smaller QR).
Every other written version is code to keep, test and explain for no new
code anyone needs, and several use the older, weaker constructions.

**Decision** (owner, 2026-11-14).

- All twelve versions are read as before.
- Only 20 and 5 are written, with Krux's refusals (repeated ECB blocks,
  NUL padding, an empty plaintext, a fresh IV). A seal of any other version
  is refused; it does not write another in its place.
- The version menu and the legacy toggle in the form go: it offers 20 and
  5.
- The read tests open codes Krux's own code made, kept as data; the
  cross-check opens all twelve and seals two.
- Every template size stays: the sizes are per size, not per version.
