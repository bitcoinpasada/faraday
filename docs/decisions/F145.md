# F145 One signed image for each piece of hardware, Strict and Open, and a Starter that carries none (2026-10-28)

**Kind:** Record
**Status:** Amended by F147
**Area:** release

*Amended by F147 (2026-10-28): one Pi image per screen for every Pi, one build per visit to the download page, images published before they are tried, marked for testers.*

**Why.** A Pi screen must be named in the card's boot files before the
Pi starts, and DPI panels cannot be detected. The DSI panels need DRM,
which the Pi kernel has kept out. Some older PCs do not start with
`efi=disable_early_pci_dma`. A Starter carrying every image for every
screen and build would grow from about 43 MB to well over 100 MB. And
whatever is written must stay a file the release key signed.

**Decision** (owner, 2026-10-28; `docs/IMAGES.md`).

- **One image per platform, screen and build**, each a release file in
  `SHA256SUMS`, built with its screen's lines in place. Nothing is
  edited after the build, by the Starter or anyone.
- **Two builds on each platform.**
  - Strict is the most the hardware allows: on the Pi, today's kernel
    (no DRM, HID or USB storage); on the PC, `efi=disable_early_pci_dma`
    on the command line.
  - Open works with more hardware: on the Pi, DRM for the DSI panels,
    HDMI, USB input and USB storage; on the PC, the kernel without the
    flag.
  - People with small screens are not affected by DRM: the Strict list
    keeps it forbidden.
- **The screens:**
  - the 2.8-inch (Strict or Open);
  - the Raspberry Pi Touch Display 2 5-inch;
  - Waveshare's 7-inch DSI (C);
  - Waveshare's 10.1-inch DSI (C) and HDMI (B);
  - an HDMI monitor with a USB keyboard and mouse.

  All but the 2.8-inch are Open. There is no 7-inch Strict image: no
  7-inch panel is known to run without DRM.
- **HDMI is allowed in the Pi's Open build**, a monitor's EDID with it.
- **A USB touchscreen named by the screen's profile is trusted input**,
  so the 10-inch HDMI panel works on its own touch with no keyboard to
  approve it. Other USB input follows the stick's approval rules.
- **The Starter carries no images**, only the release's image list. It
  offers the images it finds in Downloads or dropped on its window,
  checked against that list, and downloads nothing. The website lets a
  person tick one image or several and download each beside the
  Starter, and anyone may skip the Starter and write an image with any
  tool.

**Replaces.** `docs/STARTER.md` §9's one screen for now and deferral of
profiles (the owner's D1 and D5 there), and §9.3's single image edited
for its screen. **Amends** `docs/STARTER.md` §1.3: the Starter's payload
of images goes.
