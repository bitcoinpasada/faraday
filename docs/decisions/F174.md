# F174 A stick or card does not say it is Faraday's: plain names, its own IDs, known by its layout (2026-10-30)

**Kind:** Record
**Status:** Active
**Area:** stick
**Held by:** review

**Why.** A Faraday stick says what it is to anyone who plugs it in:
Windows shows its data partition as "FARADAYDATA (E:)" and keeps that
name in the computer's history of drives, and every file manager shows
it. Its partitions are named FARADAYBOOT and FARADAYDATA, and its GPT
IDs spell "Faraday-Stick" and are the same on every stick (F67). The
same IDs on every stick also clash: on Windows 11, a second stick
written from the same image went offline with "Collision", and when it
was brought online, Windows wrote new IDs to it, after which the Starter
no longer took it for a Faraday stick (`docs/STICK-IDENTITY.md` §2).

**Decision** (owner, 2026-10-30). This replaces F67's names and GPT
UUIDs; F67's file names and F80's sizes stand.

- The threat is a casual glance: a person who sees the stick's name in
  a file manager or the computer's history. A person who opens the
  stick's files can still tell what it is, and Learn says so.
- The names are the ones an ordinary stick or card has. On the stick,
  the boot partition is named `EFI system partition` (GPT) and labelled
  `EFI` (FAT). The data partition is named `Basic data partition`
  (GPT) and has no label. On the Pi card, the boot partition is
  labelled `bootfs` and the data partition has no label.
- Every stick and card has its own IDs. The Starter gives each one its
  own disk GUID, partition GUIDs (or, on the Pi card, MBR disk
  signature) and FAT volume serials when it writes it. The image keeps
  fixed IDs that spell nothing, so a build is still reproducible.
- After writing, the Starter checks every byte against the release
  image with this stick's IDs in place, and says that everything matches
  the release image except this stick's own IDs.
- Nothing in Faraday knows a stick by its names or its IDs. The device
  keeps back every boot partition and finds its own data partition by
  its layout and the build it holds. The Starter knows a Faraday stick
  by its layout and its boot partition's release string.
- The data partition can be named by the person, in the Starter and on
  the device.
- A stick written with another tool keeps the image's IDs. The device
  gives its data partition its own FAT serial at its first start; it
  never rewrites the partition table (F128).
- Sticks made before are not converted (no users, owner). Their layout
  is the same, so they are still known; they keep their old names until
  they are made again.
