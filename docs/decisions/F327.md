# F327 ACE's implementation and test app live in Faraday, its specification and vectors in their own repository; ACE is offered in Faraday only in Faraday Demo's dev build (2026-11-23)

**Kind:** Record
**Status:** Active
**Area:** standards
**Held by:** standards.out-of-app

*Not built. F264 stands unchanged until the code moves; the change that moves it moves F264 to `docs/history/decisions/`, as replaced by this, and STANDARDS, DEVELOPING and the README with it.*

*Replaces F264 when the code moves.*

**Why.** The owner wants the Argon Compact Envelope (ACE), including reading
its handwritten words back, tried inside Faraday before it is offered. A
library in another repository, pinned to a Faraday commit, would make each
repository depend on the other. With the implementation here, only ACE's
repository refers to Faraday, as the place its implementation is built from.

**Decision** (owner, 2026-11-23).

1. **The specification stands alone** in
   `https://github.com/bitcoinpasada/acenv`: the specification, the test
   vectors and their generator, the second reader in Python, the license,
   and the downloads of the test tool. It holds no Rust code.
2. **Faraday holds the implementation:** the library, the command line, the
   test app and its window, the fuzz targets, and a pinned copy of the
   vectors. The copy is refreshed only from a named commit of that
   repository, with the commit and the files' SHA-256 written beside it. A
   change to the format is made there first.
3. **Each release of the test tool** is published on ACE's repository and
   names the Faraday commit it was built from.
4. **ACE is offered in Faraday only in Faraday Demo's dev build** (F326),
   behind the feature `ace` (F325). Bringing it into an app that is published
   is a new decision, made after an outside review is recorded
   (`docs/AUDIT-SUBMISSIONS.md`).
5. **The ACE test tool is not one of Faraday's apps.** It stays published as
   a test tool, for test data, whatever point 4 says.
6. **No published Faraday app reaches ACE's crates.** F264 is held by
   F234's check (`tools/lint-standards.py`, check 2), which passes today
   because Faraday holds no ACE code. The change that moves the code in adds
   ACE to its `[[out_of_app]]` list, teaches the check the feature `ace`,
   and adds F325 point 3's lints.
