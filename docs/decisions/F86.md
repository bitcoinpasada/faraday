# F86 Your own randomness is mixed into the session's; the stick's kernel credits what it says it does (2026-10-23)

**Kind:** Record
**Status:** Amended by F102, F124
**Area:** security
**Held by:** tests

*Amended by F124 (2026-10-26): randomness is never collected passively; pointer and keys are a source one picks and works on; the pages open with no source running.*

*Amended by F102 (2026-10-23): nothing is said about randomness at start; a press that needs the seed waits for it, and a minute without one says the system gives none; the Pi's bcm2835-rng is mixed, not credited.*

**Why.** Every key Faraday makes by itself, and every signing round's
nonce, rests on the system's generator alone. A person who does not
trust the CPU or the operating system's generator has no way to add to
it outside New key. Separately, the stick's kernel configuration says
RDRAND and the firmware's seed are not credited, but the two options it
sets were removed in Linux 6.2, and the 6.18 kernel credits both by
default.

**Decision** (owner, 2026-10-23; the spec is `docs/OWN-RANDOMNESS.md`).

- Settings › Randomness offers Add randomness: dice and camera noise on
  every shell, and pointer movement and key timings on the desktop
  while the page is open. What is added is hashed with the system's
  bytes into the session's seed and every fresh draw; it is never used
  alone, and nothing is made before the system's first answer. The
  result is at least as strong as the stronger of the two. A status line
  says what was added; a lock wipes it.
- The stick's command line carries `random.trust_cpu=off
  random.trust_bootloader=off`, and the image check holds it, if the
  boot measurement shows the first answer within two seconds;
  otherwise the kernel's default trust is accepted and the comments say
  so. Either way the comments say what the kernel does.
- The Pi's bcm2835-rng stays built in and credited.
- The stick takes A: the two parameters are on its command line and the
  image check holds them; the boot measurement still runs, to confirm
  no long wait.
- Coins and cards are sources too, and camera noise is the default: the
  page opens on it. Add randomness is offered in Settings and New key
  only, not at boot; New key's This device mixes in what was added.
  Pointer and key timings are taken only while the page is open;
  collecting them passively from all on-screen input is set aside.
