# F306 A file in both Faraday and on the stick is a green row with a check in both cards (2026-11-21)

**Kind:** Record
**Status:** Active
**Area:** design
**Held by:** tests

**Why.** With a stick open, a person asks whether the stick holds what
Faraday holds and whether it is good to go. The cards answered it row by
row, by a grey tag on some rows and a name's presence in the other list.

**Decision** (owner, 2026-11-21; `docs/FLOWS.md` "The stick in Files").

1. A file that is in Faraday and on the stick, the same name (as FAT
   compares names) and the same bytes, has its row in both cards shown in
   the green container (`Role::OkContainer`, which follows theme, mode and
   contrast) with its text in `OnOkContainer` and a check at the end of the
   row's box. The box is the one a hover fills; hover and press still show
   over it.
2. It shows after an import, after a write read back and compared, and for
   a file already in both when the stick is opened. Not for the settings
   row and not for a file whose bytes differ.
3. Whether the bytes are the same is known when files are listed, copied or
   read back, never while drawing; for a file already on both the shell
   hashes the stick's file once and Faraday compares its own copy.

**Material.** Material 3 has no success colour, and its Foundations,
Accessible design / Color page says a state is never told by colour alone:
the check is the second signal, and the container role is the colour the
theme already carries for it. Lists gives the row, its trailing icon and its
state layer.
