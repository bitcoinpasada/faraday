# F239 A release's cross-check may be made of runs at one fresh seed, the later ones running only the areas whose own inputs changed (2026-11-10)

**Kind:** Record
**Status:** Active
**Area:** repository
**Held by:** crypto.crosscheck-combined

*Amends F197 (point 2): "after `just crosscheck --fresh`" becomes after a
fresh run, or a combination of runs at one fresh seed and scale.*

**Why.** A fresh run takes about half an hour over every area. When one
area fails and the fix is in that area's own files, running every other
area again checks nothing new: their code, their references and the
harness are as they were, at the same seed and scale, and they would give
the same answers.

**Decision** (owner, 2026-11-10).

1. **A release's cross-check is a fresh run or a combination of runs at
   one fresh seed and scale.** A later run (`just crosscheck --combine
   RECORD`, RECORD an earlier full run's record with its report beside it)
   takes the earlier run's seed and scale and no others, and runs the
   areas whose own inputs changed since and the areas that did not pass;
   every other area's result is the earlier run's.
2. **What the areas share is unchanged, or every area runs again.** The
   stamp's inputs are split into each area's own (its `area_<name>.py`
   and the reference folders only it uses) and what they share
   (everything else: the harness, Faraday's answering program, the crypto
   crates and their `Cargo.lock` entries, the vectors, the shared
   references and the tools' versions). A file two areas use, or whose
   user cannot be told, is shared. Every full fresh run's record holds the
   shared hash and each area's own; a combination refuses when the shared
   hash differs, when the earlier record holds no such hashes, or when an
   area it would take did not pass there.
3. **The combination is the release's record.** It writes the stamp and
   the record as a full run does, and both name each run it is made of:
   its date, the tree it checked and the areas it ran. `just
   lint-release` holds it as it holds a full run.
4. **Everything else in F197 stands:** the judged tests and the OVMF run
   run with each run, and point 2's `just crypto-review` and `just
   lint-release` follow the combination.
