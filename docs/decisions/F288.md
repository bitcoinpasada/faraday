# F288 While a wallet is being made, every way of making its key opens inside Make a new wallet (2026-11-18)

**Kind:** Record
**Status:** Active
**Area:** wallets
**Held by:** review

*Amends F282 (2026-11-17): "New key is one press away from Other ways" no longer holds; Other ways opens the key's cards inside Make a new wallet. The rest of F282 holds.*

*Amends F240 (2026-11-18): a single key's slot no longer offers Make SLIP-39 shares under Other forms beside the form its Backup card chose; the Backup card's choices are as F240 has them.*

**Why.** The owner's rule (2026-11-18): while a wallet is being made, no
press and no event leaves Make a new wallet for the separate New key flow.
Other ways and New key on a slot opened that flow, with its own bar, back
and Cancel, so a person making a wallet found themselves in another one.

**Decision** (owner, 2026-11-18; `docs/FLOWS.md`, A wallet's key stays in
Make a new wallet; `docs/WALLETS.md` §5).

- **The rule.** Every way of putting a key in a slot that New key offers
  (Other ways under the slot's making, New key on a slot, the foot's New
  key for Key N, the Pull sheet's resume, the Discard sheet's reopen, Make
  the rest and Add a share) is a step of Make a new wallet.
- **The shape.** The same New key state and cards open as a hosted step:
  the screen is still New key's, and the key is hosted when it was opened
  for a slot of Make a new wallet. Make a new wallet's own state is
  untouched while the key is made. The length chosen on the card is
  carried into Length; the key fills the slot on Lock in and Make a new
  wallet goes on (Check on a single key).
- **Cancel** while hosted is the key's and returns to the Keys card,
  asking first only when rolls, characters, words or a passphrase would be
  lost (F115 point 1 holds); the wallet's own Cancel is one screen back.
  Back from the key's first card returns to the Keys card with every
  answer kept and the slot empty. The sidebar's row for the wallet stays
  lit, and a stick plugged in and pulled returns to Make a new wallet.
- **Start's offers.** A slot of a single key whose Backup card chose a
  form offers that form's way of making a key only (BIP-39 words for
  Words, codex32 for Codex32 shares), not the other and not SLIP-39 shares
  under Other forms, beside every way to add a key already held. A
  multisig slot offers BIP-39 words as before. New key opened on its own
  is unchanged.
- **No new copy of a secret.** The words, rolls and passphrase stay New
  key's own state and enter the session's keys only at Lock in, as before.
