# F257 What nobody can run or reach leaves the tree (2026-11-14)

**Kind:** Record
**Status:** Active
**Area:** repository
**Held by:** review

*Supersedes F251 (the check leaves out the Starter's macOS code) and amends F89 (how silent payment signing counts a stated key), which it replaces when that signing code goes: the change that takes it out moves F89 to docs/history/decisions/. Amends F13 (the macOS apps), F234 (silent-payment sending), F208 (the YubiKey secret) and F82 (Guided mode).*

**Why.** Code that no shipped app reaches, or that runs only on a
platform nobody builds or tests, still has to be read, linted, fuzzed,
cross-checked and kept compiling at every change. Six pieces were of that
kind: the macOS code, which has no Mac to run on; silent-payment sending,
kept out of the app; a builder of recovery wallets of Liana's shape, which
only tests called; cross-check areas that compare Faraday's own code with
a model Faraday's own authors wrote; a typed YubiKey secret for vaults
that nobody has; and Guided mode's walk-through, which a first start no
longer opens.

**Decision** (owner, 2026-11-14).

1. **macOS.** The Starter's macOS code, the Mac camera shell, the plist
   reader and its fuzz target, and the hand-run macOS type-check and its
   recipe are taken out; F251's check is gone with what it checked. A Mac
   build of a shell gets the no-camera stub. What runs on a Mac without
   macOS stays: the Starter on Windows and Linux telling Mac models apart
   (`faraday/faraday-starter/src/macs.rs`) and the start guide for an
   Intel Mac (`docs/guide/start/mac-intel.md`). F13's desktop app and
   Starter on macOS, and the Starter's steps that ran on macOS, go. macOS
   comes back only by a new decision.
2. **Silent-payment sending is removed from the repository,** as FROST
   was (F127), not kept out of the app: BIP-375 signing and BIP-374
   proofs go with their tests, vectors, references and cross-check area,
   and F89's rule goes with the code it ruled. Receiving and scanning
   (BIP-352) stay, and so does the sender side of BIP-352 that its
   vectors and the cross-check need. A silent payment PSBT is still
   refused when read.
3. **The Liana-shape recovery builder goes.** Reading and signing a
   Liana wallet stay, and the helpers that reading needs (the timelock's
   days, the unspendable key) move beside it. Tests take the recovery
   wallets as fixed descriptors.
4. **Own-against-own cross-check areas go:** own randomness, the roller,
   and the cards, camera, mix and device branches of the entropy area.
   Their actions say why they are not cross-checked, their frozen vectors
   and the tests that read them stay, and they keep the label "own
   specification, not yet reviewed outside Faraday".
5. **The typed YubiKey secret goes** from F208: the Unlock field, Remove
   YubiKey secret, the response, the held secret and its seal. Key files
   stay. A KeePassXC file protected by a YubiKey reads as wrong
   credentials and fails closed, and a test holds that. No vault sealed
   with a secret exists (owner, 2026-11-14), so none needs a way to open.
6. **Guided mode's walk-through goes,** and with it the Steps only ·
   Guided switch: every flow is as Steps only showed it. A `guided` key in
   an old settings file is read and ignored. Before the walk-through goes,
   its safety lines move onto the permanent screens: compare the
   addresses before funding a wallet, and a wrong passphrase is caught at
   the slot. A sentence of it the guide lacks moves to the guide.
