# F183 The check runs on GitHub Actions: `just` on every push to main and every pull request, read-only, building nothing for release (2026-10-31)

**Kind:** Record
**Status:** Active
**Area:** repository
**Held by:** repo.ci-check

*Amended by F210 (2026-11-04): a second workflow, started by hand, runs the fuzz run before a release, under the limits of 3, 4 and 5.*

*Amended by F212 (2026-11-04): the cache of 3 may hold compiled dependencies, never Faraday's own crates.*

*Amended by F243 (2026-11-11): a third workflow, started by hand, runs one crate's tests or one lint recipe, under the limits of 3, 4 and 5.*

*Amended by F251 (2026-11-12): `lint-macos` is no longer a part of `just lint` that 2 runs.*

**Why.** The check ran only where someone ran it. A pull request
arrived with no result beside it, and nothing showed that a commit on
main still passed on a fresh machine with only the tools
`docs/DEVELOPING.md` names. GitHub runs Actions on its own runners at
no charge for a public repository.

**Decision** (owner, 2026-10-31). It replaces the rule in `CLAUDE.md`
"No hosted CI, no GitHub Actions"; "no metered external services"
stays.

1. **One workflow**, `.github/workflows/check.yml`, runs `just` on
   GitHub's Linux runners on every push to main, every pull request, and
   when started by hand. It installs the tools DEVELOPING §1 names for
   the check, at fixed versions, and nothing else
   (`.github/actions/setup/`). It passes when `just` passes: the check
   stays `just`, and a clone without GitHub checks the same way.
2. **Spread over twenty jobs** (owner, 2026-10-31), the most a free
   account runs at once: one compiles the tests once and archives them,
   fourteen each run a fourteenth of them, and the doc tests and the
   four parts of `just lint` (`lint-clippy`, `lint-deps`, `lint-repo`,
   `lint-macos`) run beside them; a last job passes when every part
   passed. The parts are recipes of the justfile, so the jobs together
   are `just` and any builder can run one part alone.
3. **It only reads.** Its token can read the repository and nothing
   more; it uses no secrets and no `pull_request_target`; the checkout
   keeps no credentials; it uses only GitHub's own actions
   (`actions/*`), each pinned by its commit. Its cache holds downloaded
   crates, the installed tools and, under F212, compiled dependencies,
   never Faraday's own crates.
4. **It builds nothing for release.** No image, no app for publishing,
   no release, no signature. Building a release on GitHub is a decision
   of its own; one that makes it puts the owner's signature only on a
   release rebuilt elsewhere and found identical.
5. **GitHub's standard runners only**, free for a public repository; no
   larger runner, which is metered.
