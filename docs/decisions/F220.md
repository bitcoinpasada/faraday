# F220 What a cosigner's partial MuSig2 signature proves on the device (2026-11-05)

**Kind:** Record
**Status:** Active
**Area:** security
**Held by:** tests

**Why.** BIP-327 says partial signatures are not signatures: `PartialSigVerify`
exists to name who aborted a round. In a PSBT the online side writes every
nonce, so it can build a partial signature for any participant that verifies
without that participant's key (all but one of the participants, or all but
the last). A device that counted a verifying partial as the participant having
signed would drop that participant's **Sign** for a signature that is not
there. No money is at risk, because the finished signature is still checked,
but the screen would say something false.

**Decision** (owner, 2026-11-05).

1. **What proves a signature.** The aggregate verifying under the output key
   (every participant); a partial this device wrote in this session and that
   verifies (its own); a secret nonce this session holds for a participant,
   which proves any entry in the file for it false.
2. **A partial that verifies and that this device cannot confirm** reads "In
   file, unconfirmed": it is not counted, not in the masters still to sign,
   and gets no **Sign**; it never reads "Verified". The count reads "{k} of
   {n} in the file" with the ones missing.
3. **A partial that does not verify**, or whose nonces are not all on the
   input, reads "Does not verify" and its master is offered **Sign**, with a
   new nonce.
4. **When every participant's partial is in the file,** Collect and opening a
   spend aggregate them with no key held and keep the signature only if it
   verifies.
5. **Masters.** A master counts per participant key, so two accounts of one
   master are two; over several inputs a master is as far along as its worst
   open input, a final input is skipped, and with every input final nobody is
   to sign.
6. **A file with another nonce for a key whose secret nonce this session
   holds.** Nothing signs under a nonce set a partial failed on. With nothing
   failing under the held nonce, it replaces the file's and **Sign** signs.
   With a partial failing, **Sign** neither signs nor refuses: the held nonce
   goes in, that partial and its spent nonce go out, the part file goes out,
   and the cosigners share and sign again.
