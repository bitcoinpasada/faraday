# F119 Faraday Desktop is Faraday Demo; its Demo mode is Practice (2026-10-26)

**Kind:** Record
**Status:** Amended by F126
**Area:** design

*Amended by F126 (2026-10-26): no `faraday-demo-…` payload file, `~/.local/bin/faraday-demo` or `Faraday Demo.exe` is made any more; the Starter removes one an earlier Starter installed.*

**Why.** The app was Faraday Desktop and its default mode was Demo, so
"Desktop or Demo" named two things that were one app and its mode. With
the app named Faraday Demo (owner, 2026-10-25), a mode also named Demo
was confusing.

**Decision.** The app is **Faraday Demo**: the wordmark reads FARADAY
DEMO, the menu entry, the Windows executable and the release files are
named for it (`faraday-demo-VERSION-linux-x86_64.xz`,
`faraday-demo-VERSION-windows-x86_64.exe.xz`, `~/.local/bin/faraday-demo`,
`Faraday Demo.exe`), and `--version` answers "Faraday Demo". The mode of
Testnet with the public samples is **Practice**: the pill reads
"Practice · Testnet", and the host strip's section of aids is headed
"Practice". The website's demo keeps its name.

Code identifiers stay: `Mode::Demo`, `Keys::demo`, `Session::set_demo`,
`DESKTOP_MODES`, the `faraday-desktop` package and `faraday/shells/desktop`,
and the document names `docs/DEMO.md`, `docs/DESKTOP-HOST.md` and
`docs/learn/faraday/demo.md`.

The Starter finds an install under the old names (`faraday-desktop`,
`app.faradayoffline.FaradayDesktop.desktop`, `Faraday Desktop.exe`,
`Faraday Desktop.lnk`, whose `--version` answers "Faraday Desktop") and
replaces it on Install and update and removes it on Uninstall.

**Amends.** F16 (the desktop app's name), F81 (the mode's name), F117 and
F118 (the app's name and the strip's section).
