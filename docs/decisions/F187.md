# F187 The Pi's screens for now: an HDMI screen and the 2.8-inch (2026-11-02)

**Kind:** Record
**Status:** Active
**Area:** release
**Held by:** review

*Amends F186 (2026-11-02): the one Pi image carries the 2.8-inch and HDMI, not the DSI screens.*

**Why.** The DSI screens (Raspberry Pi Touch Display 2, Waveshare's
7-inch and 10.1-inch DSI (C)) cost about what a cheap laptop does, and
a person who would buy one can run Faraday on the laptop instead. The
2.8-inch is cheap and an HDMI monitor is at hand for most people. Each
DSI screen would add panel, backlight, power and touch drivers to the
kernel, a probe and a program to tell the panels apart to the boot
script, and a screen offered that no one has tried. A driver not built
is code the device does not run.

**Decision** (owner, 2026-11-02; `docs/IMAGES.md` §3, §9).

1. **The one Pi image finds two screens**: HDMI when its connector
   reads connected, otherwise the 2.8-inch when its touch controller
   answers, otherwise HDMI. Both are tried on the one image before it
   is released.
2. **No DSI screen is built, listed or offered** for now; the kernel
   carries no DSI panel driver. One is added later as its own screen
   directory, drivers and probe, when its panel is at hand to try.

**Amends** F186 (every listed screen built in at once; the DSI probe
before the 2.8-inch's).
