# F82 A first start opens Steps only; Guided is a choice (2026-10-22)

**Kind:** Record
**Status:** Active
**Area:** design

**Why.** A working screen carries labels, values and actions, never an
explanation (CLAUDE.md). Guided mode's paragraphs are explanations, and a
first start opened Guided (`docs/history/SIMPLIFY.md` §6.1), so a person
met them on screens that should state only what is there.

**Decision** (owner, 2026-10-22).

- A device that has never had a setting saved opens **Steps only**. The
  Steps only · Guided switch stays beside each flow's title, and a saved
  choice is kept as before.
- Guided mode and its text are unchanged: a person who wants the
  explanations turns Guided on.
- Amends SIMPLIFY §6.1's first-start default.
