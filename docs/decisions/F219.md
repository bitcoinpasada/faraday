# F219 KEF, Krux's encrypted code, enters Faraday, all twelve versions read and written, checked against Krux's code and not on a device (2026-11-05)

**Kind:** Record
**Status:** Active, the crate and the screens built
**Area:** crypto
**Held by:** crypto.kef-claim, crypto.kef-claim-code

**Why.** A seed in a QR vault is a 77 × 77 code. KEF holds one in
33 × 33, and it is what a Krux device reads and writes, so a person can
move between the two. `docs/STANDARDS.md` §0 lets into the app a
published standard, followed and checked. KEF's cryptography is standard
AES and PBKDF2 and not Faraday's own, and it can be checked against code
Faraday did not write; but it is neither a BIP, SLIP or RFC nor a
convention other wallets use. It is one project's published format, used
by that project alone, and no outside review of it was found.

**Decision** (owner, 2026-11-05; the spec is `docs/KEF.md`).

- **KEF enters under STANDARDS §0 by this decision**, as one project's
  published format, used by that project alone, and checked against
  Krux's code and not on a device. It does not open §0 to other formats
  of one project's: each takes a decision of its own. It stands without
  a QR vault in the backup flow.
- **All twelve versions are read and written** (0, 1, 5, 6, 7, 10, 11,
  12, 15, 16, 20, 21), as in Krux v26.09.0. Versions 0 and 1 are one
  level further down and labelled legacy. Krux's refusals are kept when
  writing (`docs/KEF.md` §4.1).
- **Low error correction for version 5, one level down.** A 24-word code
  then reaches 29 × 29, and tolerates about half the damage.
- **100,000 rounds by default**, higher one level down. **An 8-byte
  random id by default**; 16 bytes, a typed label or the fingerprint one
  level down.
- **A passphrase is ASCII when writing.** On reading it is tried as
  typed, then in NFC and in NFD.
- **Left out, and the claim says so:** Krux's `seeds.json` store, and a
  passphrase that is itself a KEF code.
- **No Krux device is at hand. KEF is offered anyway**, and the claim
  (`docs/KEF.md` §2) says it was checked against Krux's code and not on a
  device. A device's code joins the vectors if one ever turns up.
- **One more piece written here:** `written_here` in
  `tools/lint-crypto.counts` goes from 39 to 40 for KEF's envelope, version
  table, checks, base43 and a PBKDF2 loop that can stop, since no library
  reads this format.
- **Faraday Starter does not scan or print a KEF code.**
