# F249 The Argon QR Vault's specification and vectors live in their own repository (2026-11-12)

**Kind:** Record
**Status:** Active
**Area:** standards
**Held by:** standards.aqrv-vectors-pinned

**Why.** A reviewer or a second implementer of the Argon QR Vault (AQRV)
wants the specification and its test vectors without Faraday around them:
no other documents, no build, no decisions of Faraday's.

**Decision** (owner, 2026-11-12).

1. **Its own repository.** The AQRV specification, its test vectors and
   the script that generates them live in `https://github.com/bitcoinpasada/aqrv`.
   The old document is moved to `docs/history/AQRV.md` as it last was here.
2. **What Faraday keeps.** The Rust reference implementation in `aqrv/`
   (library, command line and desktop test app), `tools/vectors/aqrv/diff.py`,
   Faraday's differential test of the library against the vectors'
   `check.py`, and a pinned copy of the vectors in `tools/vectors/aqrv/`
   that its tests read.
3. **The pinned copy** is refreshed only by copying the files from a named
   commit of that repository, with the commit and the files' SHA-256 digests
   written in `tools/vectors/aqrv/README.md`. The vectors are regenerated in
   that repository, never here.
4. **F245's points still hold:** the code in `aqrv/` is a test tool outside
   Faraday's apps, and bringing the format into the app is a new decision
   after an outside review.
