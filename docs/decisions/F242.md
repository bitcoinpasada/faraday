# F242 Change at an address index of 10,000 or more is change with a Caution, not verified change (2026-11-11)

**Kind:** Record
**Status:** Active
**Area:** signing
**Held by:** tests

**Why.** A change output at an index far beyond the last one used
re-derives correctly from the wallet's key, so Review counted it as
change. A wallet that scans with a gap limit never looks that far, so the
coins sent there are not found again. Other signers refuse such a key path
(BitBox02 refuses an index of 10,000 or more).

**Decision** (owner, 2026-11-11; `docs/WALLETS.md` §3.3).

- A change output whose final unhardened index, on chain 0 or 1, is 10,000
  or more is still shown as change, and Review adds a Caution
  (`WarningKind::ChangeFarIndex`) giving the output and the index, and
  saying that a wallet with a gap limit does not find coins that far.
- It applies to a single-signature key (`KeyRef::derive`) and to a
  registered wallet (`wallet_claim`, through `leaf_of`).
- It is a Caution, not a Danger: signing stays possible and nothing is
  refused. An index of 9,999 is shown as before.
