# F275 Home's Check tile only where the navigation has no Check (2026-11-16)

**Kind:** Record
**Status:** Active
**Area:** design
**Held by:** review

*Amends F255 (2026-11-16): its second point, "Home's fourth tile is Check, always", holds only on the windows whose navigation lacks Check.*

**Why.** F255 made Check a destination right under Home on the expanded
rail, the navigation rail and the Pi's menu, and gave Home a Check tile
as well. Where the sidebar lists Check the tile is a second way to the
same place on a page that is meant to hold the lead, the wallets and the
ways to start (`docs/HOME.md`).

**Decision** (owner, 2026-11-16; `docs/HOME.md` §6.3).

1. **No Check tile where Check is a destination.** The wide layout's Home
   draws no Check tile: the sidebar lists Check.
2. **The tile stays where the navigation has no Check.** The navigation
   bar keeps its five destinations without Check (F255, first point), so
   Home keeps **Check a hardware wallet**, "Its seed, addresses and
   signatures", there.

**Against Material.** Nothing: Material asks for one way to a
destination in the navigation, and a tile is a second only where the
navigation lacks it.
