# F283 Which of the plan's vaults keep a copy of the backup plan is the person's choice (2026-11-17)

**Kind:** Record
**Status:** Active
**Area:** backup
**Held by:** review

*Amends the rule in `docs/BACKUP-FLOW.md` §15.7 that every vault written holds the plan.*

**Why.** Every vault Back up wrote also took a copy of the backup plan: the places' names, what goes where, when copies were last checked. A person who keeps one vault for a place they would not have named could not leave the plan out of it.

**Decision** (owner, 2026-11-17; `docs/BACKUP-FLOW.md` §15.7, `docs/VAULT.md` §7 and §11).

- **Choice.** Each vault of the plan has **Keeps a copy of the plan**, ticked by default; any vault may be left out, all of them included.
- **Record.** The plan records only the vaults left out, one optional `unkept` line; a plan leaving none out is written as before, and a build that does not know the line reads the plan as none.
- **Write.** **Lock and write** writes the keys into every vault and the plan only into those that keep it; a plan a left-out vault already kept for the wallet is taken out.
- **Older copies.** A vault left out is still checked for an older copy: the plan's `seals` lines count a vault whose summary holds the wallet, not only one that holds its plan.
- **No plan kept.** With no vault keeping the plan it lasts until power-off; Backups and the wallet card then read "Backed up · no plan kept" for a wallet an open or known vault holds.
- **Trade-off.** The plan is no longer in every vault: a vault put back from an older copy is caught by the other vaults' `seals` lines only while one keeps the plan. Reaches main only on the owner's word after testing.
