# F263 A multisig setup file with no Format line is P2SH, as Coldcard reads it (2026-11-14)

**Kind:** Record
**Status:** Active
**Area:** wallets
**Held by:** tests

*Amends the reading of Coldcard's multisig setup file (`docs/INTEROP.md` §5), which refused a file without a `Format:` line.*

**Why.** The multisig setup file is Coldcard's format, and Coldcard
reads a file with no `Format:` line as P2SH: its own test file
`tools/vectors/wallet-files/coldcard/testing/data/multisig/export-p2sh-myself.txt`
has none, and Faraday read it as text, not as a wallet. Coldcard's
firmware source is not in the tree (only its test data and documents), so
this states what Coldcard's behaviour is as the owner gave it, and the
test file is the evidence kept here.

**Decision** (owner, 2026-11-14).

1. A multisig setup file with no `Format:` line is P2SH, the bare
   `sh(sortedmulti(...))`, because Coldcard defaults to P2SH. This accepts
   more than before; it is the owner's decision.
2. What stays refused: a `Format:` value that no multisig script here
   pays to; a key whose SLIP-132 version names another script than the
   format (with no `Format:` line a `Zpub`, `Ypub`, `Vpub` or `Upub` style
   key disagrees with P2SH and is refused as a wrong key, as a P2WSH file
   with a `Ypub` is); a key without its origin; a quorum the keys cannot
   meet.
