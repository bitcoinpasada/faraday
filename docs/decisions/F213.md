# F213 quick-xml is a library the manifest names that is not established (2026-11-05)

**Kind:** Record
**Status:** Active
**Area:** security
**Held by:** crypto.established

*Adds to F180's list of libraries the cryptography manifest names that no trusted publisher or imported audit establishes: quick-xml joins lzma-rust2 and rqrr.*

**Why.** The manifest's `vault-kdbx` action names quick-xml, the
tokenizer under the XML of a KDBX vault file. The crate is an exemption
in `supply-chain/config.toml` (F71), not covered by a publisher or an
imported audit Faraday trusts, so the check on `[[not_established]]`
(`docs/ESTABLISHED.md` §2.2) fails until the decision is recorded.

**Decision** (owner, 2026-11-05).

1. **A `[[not_established]]` entry** in `docs/crypto/actions.toml` names
   quick-xml with this decision. It does no cryptography and has no
   outside review; its default features are off and it is already in the
   dependency graph.
2. **What Faraday's own reader does** stays Faraday's: which references
   are refused, the nesting cap and everything else.
3. **The count** `not_established` in `tools/lint-crypto.counts` is 3. It
   only falls.
