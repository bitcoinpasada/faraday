# poly1305

**Cryptography:** computes

**Purpose.** Poly1305, the one-time authenticator libsodium's
`crypto_secretstream_xchacha20poly1305` uses, for opening Core Lightning's
encrypted hsm_secret (`faraday/faraday-keys/src/hsm_secret.rs`, F228). It
checks the 16-byte tag of the one message in the file; the key stream under
it is `chacha20`'s (`docs/deps/chacha20.md`).

**Why this crate.** It is RustCrypto's, with the processor's vector
instructions where it has them and a software fallback where it does not, and
the tag compare is `subtle`'s.

**Cost.** Version 0.9: one new crate in the lock file, over `cpufeatures`,
`universal-hash` and `zeroize`, which the tree already holds. Its `unsafe` is
the intrinsics backends, entered only after `cpufeatures` finds the
instructions.

**Reopen when** Core Lightning's encrypted file leaves the app.

**Review.** Trusted by publisher (github:RustCrypto/universal-hashes) under F71 (`docs/decisions/F71.md`), until 2027-10-01: `supply-chain/audits.toml`. Not read line by line here.
