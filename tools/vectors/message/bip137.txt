# BIP-137 message signatures, copied from the test suites of the two
# implementations most verifiers read (see README.md).
#
# Trezor's cases carry the mnemonic and path the key comes from; the
# Trezor test seed is "all" twelve times with no passphrase. Its NFKD
# twin of the "unusual characters" case is left out: Trezor normalises a
# message to NFC before signing and this crate signs the text it was
# given, byte for byte.
#
# Electrum's cases carry a WIF private key. Electrum writes a header in
# the p2pkh range (31 to 34) whatever the address form, which is the case
# `no-script-type: yes` stands for in Trezor's own vectors.
