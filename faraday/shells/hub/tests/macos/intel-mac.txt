# Written by hand, not recorded: layouts from Asahi Linux installer issue 141 and hst-imager's TestData/diskutil.
# An Intel Mac started from its internal disk, with a USB stick, a Faraday
# stick, a card in its SD reader, a disk image and a USB disk mounted
# outside /Volumes/ attached.
# Batch A3c replaces it with a recording made on a Mac. The layouts are
# those of the `diskutil list -plist` and `diskutil info -plist` output
# recorded in Asahi Linux's installer, issue 141, and in hst-imager's
# tests (src/Hst.Imager.Core.Tests/TestData/diskutil/); `Secure Digital`
# is IOKit's kIOPropertyPhysicalInterconnectTypeSecureDigital
# (IOStorageProtocolCharacteristics.h). Makers, models and identifiers
# are made up. Each answer follows the `===` line naming the command
# that printed it.
